
   Disc   for Atari ST

This is hard disk adaptation.
Runs on any ST(E), TT, Falcon,
from hard disk, CF card, SD card
(via Satandisk) .

Min RAM required: 1MB.
HAGA version.

Possible problem on TT, Falcon:
If you enter right after start challenge,
tournament or championship mode, 
may happen that game will stuck for
some time. I did not find so far how to
fix it. But you may solve
problem if first go in training mode and
play little. After it challenge and other
will start normally. (Esc to abort game).
